# Shreehari CD IELTS – Weekly Practice Tests

**Live Site:** [https://shreehari-extra.vercel.app](https://shreehari-extra.vercel.app)

A weekly updated **Computer Delivered (CD) IELTS** practice platform for **Shreehari Education Consultant Pvt. Ltd.**

New full-length practice tests (Listening + Reading + Writing) are uploaded **every week** for the current week’s dates.

---

## Features

- Fresh tests uploaded **every week**
- Full **IELTS Academic** practice (Listening · Reading · Writing)
- Clean & modern UI optimized for Computer Delivered exam experience
- Password-protected tests
- Mobile-friendly design
- Fast loading (hosted on Vercel)

---

## How It Works

1. Visit the homepage → you will see the current week’s available test dates
2. Click on any date (e.g. 23 Nov, 24 Nov, etc.)
3. Enter the password provided by Shreehari
4. Choose the module you want to practice:
   - Listening
   - Reading
   - Writing
5. Start the test

> **Note:** Old week’s tests are removed and new ones are added every week.
